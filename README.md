# Polaron — SEM batch-drift QC for electrode material

Hackathon project: detect when a supplier's electrode material has changed, from SEM cross-sections, and return an interpretable **accept / investigate / reject** verdict against an approved baseline.

- **Problem, data, findings, KPI catalogue, open questions:** [`docs/problem_and_findings.md`](docs/problem_and_findings.md)
- **Dataset analysis (executed notebook):** [`notebooks/01_dataset_analysis.ipynb`](notebooks/01_dataset_analysis.ipynb), generated by `notebooks/_build_01_dataset_analysis.py`
- **Per-site features:** `analysis_cache/`
- **Parallel label-free audit** (integrity, intensity/texture proxies, HTML report): `analysis/` — see `analysis/findings.md`
- **Agent / contributor guidance:** [`CLAUDE.md`](CLAUDE.md)

## Quick start

```bash
# place the data at Dataset/Batch_*/img_<site>_<detector>.tif (not tracked by git)
python3 notebooks/_build_01_dataset_analysis.py
cd notebooks && jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=2400 01_dataset_analysis.ipynb
```

Requires Python 3.12 with numpy, scipy, scikit-image, scikit-learn, pandas, matplotlib, statsmodels, tifffile, jupyter.
