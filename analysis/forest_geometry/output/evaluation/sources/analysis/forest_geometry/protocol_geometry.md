# E41S geometry extraction protocol

Registered before this experiment's model scores. Fixed eight existing image-geometry candidates: three equal-component-weight shape-distribution summaries, two centreline-pooled void-width summaries, bright-centroid 3-NN spacing IQR/median, original bright-mask window SD at 512 px, and signed-lag bright/void x-minus-y association at 256 px. All remain **unvalidated predicted-mask geometry**, experimental classification-only inputs. No human labels, battery outcomes, physics-law values or pixelwise chemical claims are supplied.

Shape uses 8-connected bright components, area >=50 px², excludes every trimmed-frame edge-clipped object and requires >=20 interior components with positive area, minor axis and perimeter. The aspect ratio uses major/minor directly; circularity uses raster perimeter and is not clipped at one; solidity uses raster convex area. Shape quantiles use linear interpolation and equal component weights, matching E30K. Graph uses the unique undirected union of each eligible centroid's three nearest distinct neighbours, deterministic coordinate tie-breaking, excludes clipped nodes, and requires >=10 nodes and >=10 edges with positive median length, matching E26G.

Void widths follow E24: >=30 px² 8-connected void components, exclude clipped objects, deterministic medial axis (seed 20261003), sample 2*Euclidean distance at centreline pixels; median/Q90 pool these pixels. This is a length-weighted 2-D width proxy, not independent observations, maximal-disk thickness, throat size or 3-D tortuosity. The floor50/floor100 probe refers **only to bright shape/graph objects**; the void floor remains30. Empty centreline coverage is unavailable (NaN), not zero.

Window SD uses population SD of original-mask bright area fractions over complete top-left-anchored 512x512-px non-overlapping windows, >=2 windows and some bright pixels in their union. It matches the exact E25 local-SD convention, without recomputing unrelated component rings. Partial edge windows are excluded. Cross-correlation uses signed +/-256-px bright-to-void Pearson correlations along both image axes, each with its own finite overlapping domain and marginals; x mean minus y mean. Every signed domain needs >=10,000 paired pixels and >=100 phase/complement pixels for both masks, matching E30K. Image x/y axes remain unverified electrode axes. Full-field window/graph/correlation summaries retain extent/sampling dependence even with frame height excluded from predictors.

All raw extraction uses the current adaptive BSE edge-band trim, Gaussian smoothing sigma1 and histogram-anchored threshold pair. Nominal caches reuse exact compatible E30K shape/correlation, E26G graph, E24 width and E25 local-SD definitions. Reuse is explicit: hash-bind current caches and historical manifests; verify all known raw BSE digests, compatible threshold/quality metadata and method semantics; freshly replay all8 on four fixed cases (ordinary Batch2/3806gxp0, low-contrast Batch1/4ih2ggld, raised-black-level Batch3/71vgq3fw, cracked Batch3/hzumfsms). E24's old feature-module digest predates later helper additions; its width result hash and current width-method hash are also bound by E25's void-recovery manifest. Unrelated E25 ring-description edits do not alter the window-SD function; AST body equivalence is checked and raw replay demonstrates the local-SD definition. Snapshot input/source hashes and source text before extraction. Fresh example parity is a compatibility check, not phase truth or proof of every cache cell's accuracy.

Known31 nominal plus fixed joint threshold offsets -5/+5 (move both th_lo and th_hi) and bright floor100 make124 site-variant rows. Raster window/correlation and void-width values are **identical by design** between nominal and floor100; this is not robustness evidence. Baseline image-derived quality flags remain fixed under threshold/floor probes; no invalid mask becomes eligible from perturbing it. Crop/variant uniqueness is validated before every join, and nominal selection is explicit. Variants/tile counts do not multiply n.

Model inputs use E37S's data-derived fail-closed `quality` policy. Bright shape/graph/window require known-good bright separation; width requires known-good pore quality (raw integer BSE p1<=10); association requires both. Unknown quality, non-finite measurements or insufficient coverage produce NaN with explicit reasons. Quality statistics, counts, IDs, frame geometry and clipping fields are diagnostics, never model predictors. Training-fold imputation is a downstream model step. Coverage and imputation patterns can still encode source/session conditions.

First-drop extraction is a separate explicit command gated by a saved known-only model-stage receipt. It reads raw BSE only, does not read organiser truth or outcomes, and writes cohort metadata as `first_drop_development` with batch equal to the source-folder label, not a supplied class. The3 revealed crops are development diagnostics, not validation. A new34 view may join the labels downstream only after known-only fits and metrics are saved.

Artificial batch labels identify curated visual groups. Around15 source images does not establish15 independent specimens. Parent crop IDs remain unknown: all classifier held-out-crop scores remain potentially source-leaking diagnostics. Frozen v2/QC, raw TIFFs, original caches and previous experiment artifacts remain unchanged.
